\begin{question}{Programming / Programmieren}%
\begin{equation}%
\log{x} \approx 3(x^2 - 1)/((x+ 1)^2 + 2x)%
\end{equation}%
%
\qENDE{%
The equation above was given by \citeauthor{K1987EFFAC} in~\cite{K1987EFFAC} as an approximation for the natural logarithm of~$x$, i.e., $\log{x}$, for values of~$x$ close to~$1$.
This means that it does \emph{not} return the values of $\log{x}$ exactly, but it computes values very close to them.
And this only works if $x\approx 1$.
But it has the advantage that it is fast.%
\begin{enumerate}%
\item Implement the right-hand-side of the equation as a function.%
\item Annotate the function with \pglspl{typeHint} and a \pgls{docstring}.%
\item How would you test this function? Remember that it only is an approximation. Write some \pglspl{doctest} in the \pgls{docstring}.%
\end{enumerate}%
%
}{%
Die Gleichung oben wurde von \citeauthor{K1987EFFAC} in~\cite{K1987EFFAC} als eine Annäherung des natürlichen Logarithmus von~$x$, also~$\log{x}$, für Werte von~$x$ nahe~$1$.
Das bedeutet, dass die Formel \emph{nicht} die exakten Werte von~$\log{x}$ berechnet, sondern nur Werte \emph{nahe} an ihnen.
Das funktioniert auch nur für~$x\approx 1$.
Aber es ist schnell.
\begin{enumerate}%
\item Implementieren Sie die rechte Seite der Gleichung als eine Funktion.%
\item Annotieren Sie die Funktion mit Type-Hints und einem DocString.%
\item Wie würden Sie diese Funktion testen? Bedenken Sie, dass sie nur eine Näherung ist. Schreiben Sie ein paar DocTests in den DocString.
\end{enumerate}%
}%
\end{question}%
