\item[DE] Die Variable \pythonil{lists} speichert eine Liste von Listen von Ganzzahlen, zum Beispiel sowas wie \pythonil{[[1, 2], [3], [-1, 2, 3]]}. %
Schreiben Sie \python-Kode der eine neue Liste \pythonil{flat} erstellt, die eine Liste von Ganzzahlen ist und die selben Elemente wie \pythonil{lists}, einhaltet, zum Beispiel \pythonil{[1, 2, 3, -1, 2, 3]}. %
Mit anderen Worten, Ihr Kode muss eine beliebige Liste-von-Listen-von-Ganzzahlen \pythonil{lists} nehmen nd eine Liste \pythonil{flat} mit den selben Ganzzahl-Elementen erstellen.%
